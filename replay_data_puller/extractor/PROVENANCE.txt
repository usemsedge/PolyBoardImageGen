Reusable api.py helpers (without lz4)
------------------------------------
api.py has standard-library top-level imports; no top-level requests or writes.
Load it explicitly from its trusted absolute path under Python -I, independently
of cwd. Do not import the package __init__.py or run __main__.py: they use bare
sibling imports. Snapshot/token/UUID helpers require neither lz4 nor GameState.

Token discovery: _data_roots() -> list[Path], find_jwt_files() -> list[Path],
newest_jwt() -> Path | None, load_jwt() -> str (takes NO arguments). On Windows,
roots include home/AppData/LocalLow, LOCALAPPDATA or home/AppData/Local, and
home/AppData/Roaming. macOS/Linux Unity roots are also tried. DIR_GLOBS matches
com.midjiwan.polytopia*, *polytopia*, *Polytopia*, *midjiwan*, *Midjiwan*; recursive
exact jwtToken files are resolved/deduplicated; newest st_mtime wins. load_jwt
reads UTF-8 and strips, raising FileNotFoundError for absent/empty token. These
helpers do not print the token; keep credentials in memory, never logs or argv.
Caveats: broad discovery, symlink targets outside roots, filesystem races/errors,
unbounded token reads, and no validation of token expiry or authenticity.

It does not enforce a trusted share host or require the entire input to match.
Its ValueError embeds the supplied input; do not log unrelated HAR strings.

Response/error/state schema observed in this archive
---------------------------------------------------
api.py accesses envelope success, data, errorMessage, errorCode. data fields
accessed are id, state, dateCreated, dateLastCommand, ownerId, gameSettingsJson,
timerSettings, gameContext, currentGameStateData and initialGameStateData. This
is not an exhaustive response schema and unknown fields must be retained.
api.py defines STATE_ENDED = 4, commented as GameSessionState.Ended; its comment
calls state 3 in-progress. It defines NO ErrorCode enum and NO complete
GameSessionState enum. Do not infer success from errorCode == 0. Exact complete
server enum names/numbers require separately established native definitions.
model.py's DIFFERENT snapshot GameState.State is documented as Unknown=0,
Lobby=1, Started=2, FinalTurn=3, Ended=4. wire.py comments mention
ErrorCode.GameStateDeserializationFailed (1012), but define no ErrorCode enum.

Snapshot wrapper versions without importing wire.py/lz4
-----------------------------------------------------
wire.deserialize reads signed little-endian int32 outer_version at offset 0
and GameState.Version at offset 4, then requires equality. For an API base64
snapshot, len(blob) >= 8 permits struct.unpack_from("<ii", blob, 0) to inspect
both headers without full parsing, importing wire.py, or requiring lz4. Preserve
unknown/mismatched values and raw blobs rather than rejecting them. This layout
is for uncompressed API snapshots, NOT the first bytes of K4os .state files.
wire.serialize_api_blob writes those same two int32 headers. K4os .state pickle
flags use low 3 bits for pickle version (supported version 0), high 2 bits for
a signed size-difference field of 0/1/2/4 bytes; field length 0 is uncompressed
payload after the flags byte. Compressed paths need lz4.block. Even uncompressed
lz4_unpickle imports lz4.block before inspecting flags. Local/hotseat payloads
then begin with a version and contain two/three serialized GameStates.
wire constants CURRENT_VERSION=122, LOCAL_SAVE_VERSION=116, LIVE_SAVE_VERSION=123
are upstream codec assumptions, NOT collector filters or proof of renderability.

Review concerns: upstream pathways not suitable for collector reuse
------------------------------------------------------------------
- api_post logs HTTP error bodies; _api_post_curl puts Bearer JWT in process argv,
  and exception tracebacks can expose it. Curl paths log stdout/stderr and invalid
  JSON bodies. Avoid these transport/error logging paths.
- fetch_game_view_model logs complete failures and falls back indiscriminately;
  it does not distinguish authentication, explicit access denial or rate limits,
  and discards the first response when fallback succeeds.
- Response reads are unbounded. urllib has a 60-second timeout; curl fallback has
  no explicit timeout, does not fail on HTTP status, and loses status/headers.
- build_output requires a current blob and reduces/renames response fields.
  fetch_game_data defaults ended-only and caches beside executable source.
  Do not use reduced output, ended gate or .share_cache as the raw archive.
- Package entrypoints use cwd-sensitive sibling imports. model.py lazily imports
  absent mapgenerator.settings in GetMapGeneratorSettings. requirements.txt has
  an unpinned lz4 dependency. No dependency was installed for this review.
- Full binary parsing is version/layout-dependent, rejects header mismatches,
  unknown command/action layouts and trailing bytes, permits recursive units,
  and has no comprehensive size/count/depth limits. Do not run full parsing on
  responses merely to persist them. Reduced JSON conversion also loses fields.
- Preserved upstream code is not an approval to execute installers, fetch live
  data, bypass service protections, log secrets, or redistribute unlicensed code.
